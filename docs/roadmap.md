# Development Roadmap

Items below are goals, not claims that the features are already complete.

- [ ] Confirm final ESP32-C3 board and GPIO/ADC pin mapping.
- [ ] Publish a verified wiring diagram.
- [ ] Capture calibration data for index, middle and ring sensors.
- [ ] Define and document the supported gesture vocabulary.
- [ ] Implement stable filtering and gesture classification.
- [ ] Test recognition accuracy over repeated trials.
- [ ] Polish the Wi-Fi web dashboard and document access steps.
- [ ] Add speech output if the core gesture recognition is reliable.
- [ ] Design a durable, comfortable sensor mounting system.
- [ ] Document battery protection and power testing before portable use.
- [ ] Publish a short demonstration video with consent from everyone shown.
