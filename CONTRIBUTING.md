# Contributing

Thanks for your interest in EmpowerGlove!

## Before contributing
- Explain the problem or improvement clearly.
- For hardware changes, include the board model, sensor model and wiring/pin mapping.
- For firmware changes, include build environment and compiler/library versions.
- Never commit Wi-Fi passwords, API keys, private recordings or personal information.

## Pull requests
1. Create a focused branch.
2. Describe what changed and why.
3. Include test steps and observed results.
4. Update documentation and the changelog when relevant.
5. Do not describe untested features as working.

## Safety
This is an experimental prototype, not a certified medical device or a replacement for established communication or accessibility support.
